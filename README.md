# 常用网址排行（Chrome 插件）

从 Chrome 浏览历史中统计最常访问的网站和网址，点工具栏图标就能看到排行，点一下就能打开。所有统计都在本机完成，不联网。

## 安装

1. 打开 `chrome://extensions`
2. 打开右上角的「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目根目录（包含 `manifest.json` 的文件夹）
4. 把工具栏里的插件图标固定出来，点击即可使用

修改代码后，在 `chrome://extensions` 里点插件卡片上的刷新按钮即可生效。

## 功能

- **统计方式**：按域名（`github.com` 下所有页面合在一起，默认）或按网址
- **时间范围**：全部 / 近 30 天 / 近 7 天 / 今天
- **排序**：访问次数、手动输入次数、最近访问、综合（访问次数 + 新近程度，14 天没去分数减半）
- **搜索**：按标题、网址过滤，显示的是该条目在完整排行里的名次
- **每行的 ⋯ 菜单**：复制链接、置顶、隐藏、屏蔽该域名
- **设置页**（弹窗右上角 ⚙）：显示条数、打开方式、屏蔽域名、管理已隐藏和已置顶的条目、只统计本机访问

### 快捷操作

| 操作 | 效果 |
|---|---|
| 单击 | 打开网址（新标签页或当前标签页，可在设置里改） |
| Ctrl / ⌘ + 单击、鼠标中键 | 在后台标签页打开，弹窗不关 |
| ↑ ↓ | 选择条目 |
| Enter | 打开选中的条目（没有选中时打开第一条） |
| Esc | 关闭菜单 → 清空搜索 → 关闭弹窗 |

## 统计口径

- **全部**：直接使用 Chrome 记录的总访问次数。Chrome 默认只保留约 90 天的历史。
- **30 天 / 7 天 / 今天**：逐条读取每个网址的访问明细再统计，历史很多时需要一两秒，底部会显示进度。
- **只统计本机访问**：依赖 Chrome 115+ 提供的 `isLocal` 字段，只在选择时间范围时生效。
- **加载缓存**：最近一次统计结果在浏览器会话内缓存 30 秒，重复打开弹窗可以复用；新增或删除历史会自动使缓存失效（弹窗打开期间不会自动刷新，切换范围或重新打开时更新）。缓存不写入磁盘，超出大小限制或缓存不可用时直接读取历史。
- 切换时间范围会复用未变化网址的访问明细，并停止旧范围尚未发出的请求；首次统计大量历史仍需要读取明细。
- 不统计 `chrome://`、`file://`、扩展页面等非网页地址。
- 按网址统计时会忽略普通锚点（`#section`）；单页应用的 hash 路由（`#/path`）视为不同页面。开启「合并只差追踪参数的网址」后，还会忽略 `utm_*`、`gclid`、`spm` 等参数。

## 权限

| 权限 | 用途 |
|---|---|
| `history` | 读取浏览历史（安装时 Chrome 会提示“读取和更改浏览记录”，插件只读不改） |
| `storage` | 保存设置、屏蔽/隐藏/置顶列表 |
| `favicon` | 显示网站图标（读取 Chrome 本地缓存，不联网） |

## 项目结构

```
manifest.json
src/background.js      监听历史变更，使会话缓存失效
icons/                 由 scripts/make-icons.mjs 生成
src/core/              纯逻辑，不依赖 DOM
  history-source.js    读取 chrome.history，按时间范围统计
  history-loader.js    复用明细和短期会话缓存
  normalize.js         网址规范化、域名提取、屏蔽规则匹配
  aggregate.js         按域名 / 网址归并
  rank.js              排序策略
  pipeline.js          屏蔽 → 归并 → 排序 → 隐藏 → 置顶
  settings.js          设置读写（chrome.storage.local）
  format.js            数字、时间、图标地址格式化
src/popup/             弹窗
src/options/           设置页
tests/                 单元测试（node:test）
dev/                   开发预览：假 chrome API + 静态服务器
```

## 开发

需要 Node.js 20 或更新版本，无第三方依赖。

```bash
npm test
```

```bash
npm run dev
```

`npm run dev` 启动预览服务器后，打开 <http://localhost:5178/dev/preview.html?page=popup>（弹窗）或 `?page=options`（设置页）。预览页用 `dev/mock-chrome.js` 模拟浏览历史和存储，界面直接载入 `src/` 下的真实代码。预览里没有网站图标，显示的是首字母头像。

重新生成图标：

```bash
npm run icons
```
